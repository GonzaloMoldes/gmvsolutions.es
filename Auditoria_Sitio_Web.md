# Auditoría Completa de un Sitio Web

Checklist de referencia para valorar si un sitio web transmite profesionalidad, funciona correctamente y está preparado para convertir visitas en resultados. Pensada para usarse página a página o como revisión general del dominio.

## 1. Primera impresión y branding

*Lo que un visitante percibe en los primeros segundos, antes de leer nada en detalle.*

| Punto a revisar | Estado | Notas |
|---|---|---|
| Coherencia de colores, tipografías y logo con la identidad corporativa | | |
| Calidad y originalidad de las imágenes (evitar banco de imágenes genérico) | | |
| Propuesta de valor clara y visible en los primeros 5 segundos | | |
| Consistencia del tono de voz en todos los textos | | |

## 2. UX y navegación

| Punto a revisar | Estado | Notas |
|---|---|---|
| Menú claro, con jerarquía lógica de contenidos | | |
| CTAs (llamadas a la acción) visibles, contrastadas y repetidas a lo largo de la página | | |
| Formularios simples, sin campos innecesarios | | |
| Experiencia adaptada a móvil (responsive real, no solo "que se vea bien") | | |
| Buscador interno si el volumen de contenido lo justifica | | |
| Tiempo hasta encontrar la información clave (test de "3 clics") | | |

## 3. Rendimiento técnico

| Punto a revisar | Estado | Notas |
|---|---|---|
| Velocidad de carga (Core Web Vitals: LCP, CLS, INP) | | |
| Imágenes optimizadas y en formatos modernos (WebP/AVIF) | | |
| Sin errores 404 ni enlaces rotos | | |
| HTTPS correctamente configurado, sin contenido mixto | | |
| Compatibilidad entre navegadores y dispositivos | | |

## 4. SEO on-page

| Punto a revisar | Estado | Notas |
|---|---|---|
| Títulos y meta descripciones únicos por página | | |
| Estructura de encabezados coherente (un único H1, jerarquía H2-H3 lógica) | | |
| URLs limpias y descriptivas | | |
| Datos estructurados (schema.org) donde aplique | | |
| Sitemap.xml y robots.txt correctos y actualizados | | |
| Enlazado interno coherente entre páginas relacionadas | | |

## 5. Contenido

| Punto a revisar | Estado | Notas |
|---|---|---|
| Sin errores gramaticales u ortográficos | | |
| Textos orientados a beneficios, no solo a características | | |
| Prueba social: testimonios, casos de uso, logos de clientes | | |
| Contenido actualizado (fechas, copyright, blog activo si existe) | | |
| Consistencia terminológica en todo el site | | |

## 6. Confianza y credibilidad

| Punto a revisar | Estado | Notas |
|---|---|---|
| Página "sobre nosotros" con información real y verificable | | |
| Datos de contacto visibles (teléfono, email, dirección) | | |
| Política de privacidad, aviso legal y cookies conformes a RGPD | | |
| Certificados, sellos o menciones en prensa si los hay | | |

## 7. Conversión y analítica

| Punto a revisar | Estado | Notas |
|---|---|---|
| Tracking correcto (GA4/GTM) sin bloqueos por CSP u otras políticas | | |
| Eventos de conversión bien definidos y verificados en tiempo real | | |
| Funnel de usuario claro en cada página (qué acción se espera) | | |
| Mapas de calor o grabaciones de sesión, si se usan, revisados periódicamente | | |

## 8. Accesibilidad

| Punto a revisar | Estado | Notas |
|---|---|---|
| Contraste de color suficiente (WCAG AA como mínimo) | | |
| Textos alternativos en todas las imágenes relevantes | | |
| Navegación completa por teclado | | |
| Tamaños de fuente legibles en todos los dispositivos | | |

## 9. Seguridad

| Punto a revisar | Estado | Notas |
|---|---|---|
| Certificado SSL válido y renovado automáticamente | | |
| Cabeceras de seguridad activas (CSP, HSTS, X-Frame-Options) | | |
| Backups periódicos y plan de recuperación ante fallos | | |
| Plugins, librerías y dependencias actualizados | | |

## 10. Cumplimiento legal

| Punto a revisar | Estado | Notas |
|---|---|---|
| Banner de cookies funcional y configurado correctamente | | |
| Aviso legal y condiciones de uso publicados | | |
| Política de privacidad conforme a RGPD/LOPD-GDD | | |

## Cómo usar esta guía

1. Recorre el site como lo haría un visitante nuevo antes de entrar en modo técnico.
2. Marca cada punto como OK / Revisar / No aplica en la columna "Estado".
3. Prioriza primero lo que afecta a confianza y conversión, después SEO y rendimiento, y por último detalles estéticos.
4. Repite la auditoría de forma periódica (trimestral o tras cambios importantes en el site).
